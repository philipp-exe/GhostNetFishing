# Ghost Net Fishing

Fallstudie für IPWA02-01 (Programmierung von industriellen Informationssystemen
mit Java EE). Meldet und verwaltet Geisternetze für die (fiktive) Organisation
"Shea Sepherd".

Umgesetzt: 5 der 7 User Stories aus dem Product Backlog (Sprint 1).

JSF/CDI/JPA auf Apache TomEE, H2 als Datenbank – kein Server, den man extra
aufsetzen müsste.

## Starten

```bash
mvn tomee:run
```

→ http://localhost:8080/GhostNetFishing/
